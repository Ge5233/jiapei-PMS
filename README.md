# 产品管理系统（PMS）部署文档

> 适用：腾讯云轻量服务器 + 宝塔面板 + MySQL 5.7 + PHP 8.2
> 访问方式：服务器公网 IP + 端口 `8081`
> 不需要域名、不需要 HTTPS

## ⚠️ 部署前确认

| 项 | 你的服务器情况 | 影响 |
|---|---|---|
| 扣子应用 | 跑在端口 5000 | **本系统不会动它**（独立端口 8081） |
| MySQL | 5.7 已装 | 直接复用，**新建一个数据库** `pms_db` |
| PHP | 还没装 | 装 PHP 8.2（不会影响扣子应用） |

---

## 第 1 步：装 PHP 8.2

1. 登录宝塔面板（一般是 `http://服务器IP:8888`）
2. 左侧菜单点 **"软件商店"**
3. 顶部标签点 **"运行环境"**
4. 找到 **PHP 8.2**，点 **"安装"**
5. 弹窗选 **"极速安装"**，等待 1-3 分钟
6. 装完后左侧菜单 **"网站"** → 顶部 **"PHP 命令版本"** 应该能看到 8.2

> 💡 如果列表里没有 PHP 8.2，可能是宝塔版本太老，先在"软件商店"首页点"更新软件列表"。

---

## 第 2 步：建数据库

1. 左侧菜单点 **"数据库"**
2. 顶部点 **"添加数据库"**
3. 填写：

| 字段 | 填什么 | 备注 |
|------|--------|------|
| 数据库名 | `pms_db` | |
| 用户名 | `pms_user` | |
| 密码 | 点 **"生成"** 按钮 | ⚠️ **复制保存到记事本！** 后面要用 |
| 访问权限 | 本地服务器 | |
| 编码 | `utf8mb4` | |

4. 点 **"提交"**
5. 列表里能看到 `pms_db` 就成功了

---

## 第 3 步：建站点

1. 左侧菜单点 **"网站"**
2. 顶部点 **"添加站点"**
3. 填写：

| 字段 | 填什么 |
|------|--------|
| 域名 | **留空**（IP 模式） |
| 备注 | `产品管理系统`（方便识别） |
| 根目录 | 默认即可（一般是 `/www/wwwroot/pms.xxx`） |
| FTP | **不创建** |
| 数据库 | **不创建**（我们在第 2 步已经建好了） |
| PHP 版本 | **PHP-8.2** |

4. 点 **"提交"**
5. ⚠️ **记住这个站点的根目录路径**（列表里点"根目录"列可以看到，例如 `/www/wwwroot/pms.172.16.0.1`）

---

## 第 4 步：改端口

新站点的默认端口是 80，我们要改成 8081：

1. **网站列表**里找到刚建的站点
2. 点 **"设置"** 按钮
3. 左侧菜单点 **"域名管理"**
4. 删掉默认的 `服务器IP:80` 那行
5. 顶部 **"添加域名"** → 域名填 `你的服务器公网IP` → 端口填 `8081`
6. 点 **"添加"**
7. 保存

> 看到列表显示 `你的IP:8081` 就 OK 了

---

## 第 5 步：放行端口（重要！）

不开放端口外网访问不了。两层都要放行：

### 5.1 腾讯云控制台（外层）
1. 登录 https://console.cloud.tencent.com
2. 找到你的轻量服务器实例
3. 点 **"防火墙"** 标签
4. 顶部点 **"添加规则"**
5. 填写：
   - 协议：TCP
   - 端口：`8081`
   - 备注：`PMS系统`
6. 点 **"确定"**

### 5.2 宝塔面板（内层）
1. 宝塔左侧菜单 **"安全"**
2. 顶部 **"添加端口规则"**
3. 填写：
   - 协议：TCP
   - 端口：`8081`
   - 方向：入站
   - 备注：`PMS系统`
4. 点 **"确定"**

---

## 第 6 步：上传代码

1. 把项目代码打包成 `pms.zip`（如果你是从开发者那里拿到的，开发者会给你）
2. 宝塔左侧菜单 **"文件"**
3. 顶部路径栏输入第 3 步记下的站点根目录，例如 `/www/wwwroot/pms.172.16.0.1/`
4. 回车进入目录
5. 点顶部 **"上传"** 按钮
6. 拖拽 `pms.zip` 进去，等待上传完成
7. 选中 `pms.zip` → 右键 **"解压"** → 选 **"解压到当前目录"**
8. 解压后能看到一堆 php 文件 + sql/ + includes/ 等目录

---

## 第 7 步：运行安装向导

1. 浏览器访问：`http://你的服务器IP:8081/install.php`
2. 看到 5 步引导界面，跟着走：

| 步骤 | 操作 |
|------|------|
| ① 环境检查 | 自动检测 PHP 扩展、目录权限，**全部 ✅ 才能继续** |
| ② 数据库配置 | 填第 2 步的数据库信息：<br>- 地址：`localhost`<br>- 库名：`pms_db`<br>- 用户：`pms_user`<br>- 密码：第 2 步保存的密码<br>点 **"测试连接"**，通过后下一步 |
| ③ 建表 | 自动执行 6 张表的 SQL，约 10 秒 |
| ④ 创建账号 | 创建默认管理员 `admin / 123456` |
| ⑤ 完成 | 显示成功页面，提示删除 install.php |

3. 安装成功后，**回到宝塔** → 文件 → 站点根目录 → 删除 `install.php`

---

## 第 8 步：首次登录 + 改密码

1. 浏览器访问：`http://你的服务器IP:8081`
2. 登录：`admin` / `123456`
3. 系统**强制要求**改密码（不能跳过）
4. 改完后进入系统，**开始使用** ✅

---

## 🎉 部署完成

- 系统地址：`http://你的服务器IP:8081`
- 默认账号：`admin` / 你的新密码
- 建议接下来：
  1. **首页**先点一下看看通不通
  2. **分类管理**先建几个分类（一级 + 二级）
  3. **产品管理**加 1-2 个产品试试
  4. 给同事**新建账号**（员工角色）

## 🆘 常见问题

### Q1：访问 `http://IP:8081` 显示"无法访问此网站"
- 检查腾讯云防火墙是否放行 8081
- 检查宝塔"安全"是否放行 8081
- 检查第 3 步建站点时端口是否填了 8081

### Q2：访问 `http://IP:8081/install.php` 显示 404
- 确认第 6 步上传代码后有 `install.php` 文件
- 确认解压到了正确的站点根目录

### Q3：安装时"测试连接"失败
- 数据库信息填错（库名/用户名/密码对一下第 2 步保存的）
- MySQL 服务没启动（宝塔 → 软件商店 → MySQL → "启动"）

### Q4：安装时"环境检查"红色叉
- PHP 8.2 没装好（重装）
- 目录权限问题（站点根目录给 755 权限，uploads/ 给 777）

### Q5：登录后页面空白
- 浏览器按 F12 看 Console 错误
- 截屏给开发者排查

### Q6：忘记了密码
- 用 SSH 连服务器，参考 `docs/reset-password.md`（如果开发者提供了的话）
- 或者用宝塔 phpMyAdmin 直接改数据库

## 🔄 后续维护

### 备份数据库
1. 宝塔 → 数据库 → 找到 `pms_db`
2. 点 **"备份"** → 点 **"备份"** 按钮
3. 备份文件会保留在 `/www/backup/database/`

### 升级代码
1. 把新代码打包成 zip
2. 宝塔 → 文件 → 站点根目录 → 上传解压覆盖
3. 浏览器访问一次 `install.php`（**不要点安装**，只会显示"已安装"）

### 不影响扣子应用
- 本系统跟扣子应用**完全独立**：
  - 不同端口（8081 vs 5000）
  - 不同数据库（pms_db vs 扣子的库）
  - 不同目录
- 你随便折腾本系统，**不会影响扣子**

---

## 📞 紧急情况

如果系统出问题了，但扣子应用还正常：
- 说明只是 PMS 自己崩了
- 宝塔 → 网站 → 找到 PMS 站点 → "重启" PHP
- 实在不行联系开发者
